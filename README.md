# marginnote-anki

把 **MarginNote / Anki 导出的卡片包（`.apkg`）** 转成一套能直接用的复习材料：

- 📱 **单文件离线卡册网页** —— 图片全部内联，一个 HTML 就是整个题库，微信直接传、断网能开
- 🖨️ **A4 打印版 PDF** —— 题目在上、答案在下，虚线分隔，适合打印出来背
- 🗂️ **多科目管理首页** —— 数学分析、高等代数各放各的，自动生成资料库目录页

不需要安装 Anki，不需要联网，不依赖任何第三方 Python 包（只要标准库）。

---

## 它解决什么问题

Anki 桌面版能背，但有两个麻烦：

1. **换设备就断** —— 手机上要装 App，题库导来导去很容易丢进度
2. **不方便打印** —— Anki 的打印功能几乎不可用，而数学类卡片全是公式截图，必须印出来手写

这个工具把 `.apkg` 一次性展开成静态网页：图片、标签、翻面逻辑全部压进一个 HTML 文件，任何浏览器都能打开，想印就印。

对 MarginNote 3 导出的牌组额外做了适配（这类牌组用挖空 SVG + 答案截图的方式做正反面）。

## 功能

| 功能 | 说明 |
|---|---|
| 翻面复习 | 点卡片或空格翻面，← → 切卡，手机上左右滑动 |
| 标签搜索 | `A B` 取并集（含 A **或** B），`A\|B` 取交集（同时含 A 和 B），支持混合与子串匹配 |
| 标签筛选 | 顶部标签 chip 一键过滤，实时显示命中数量 |
| 打乱顺序 | 随机洗牌，避免按固定顺序形成位置记忆 |
| 目录抽屉 | 列出全部卡片，带出处页码，点击跳转 |
| 图片放大 | 点图全屏看原图像素，书上的公式能看清 |
| 记忆进度 | 当前卡片存 localStorage，下次打开接着看 |
| 深链 | `xxx.html#30` 跳到第 30 张，`#30b` 跳到答案面，`#q=曲面` 预填标签搜索 |
| 打印 | 打印/PDF 按钮或快捷键 `P`，**只打印当前筛选出的卡** |

## 快速开始

**1. 准备卡片包**

在 `源文件/` 下按科目建文件夹，把 `.apkg` 丢进去。支持多级目录：

```
源文件/数学分析/xxx.apkg          → 科目显示为「数学分析」
源文件/考研/数学分析/xxx.apkg     → 科目显示为「考研 / 数学分析」
源文件/xxx.apkg                   → 科目显示为「未分类」
```

> 微信传过来的文件常被改名成 `.apk.1g`、`.apk.1` 之类。这个脚本**不看后缀看内容**（按 zip 里有没有 `collection.anki2` 判定），直接丢进去就行。

**2. 运行构建**

```bash
python build.py            # 全量重建：卡册 + PDF + 首页
python build.py --no-pdf   # 跳过 PDF，速度快很多
```

只依赖 Python 3.8+ 标准库。

**3. 打开 `index.html`**

首页会按科目分组列出所有牌组，点「打开卡册」或「PDF」即可。

以后新增/删除题库，重新跑一次 `build.py` 就会自动刷新 —— 源文件删掉的牌组，对应的卡册也会被自动清理。

## 关于 PDF

PDF 用 Chromium 内核的「打印到 PDF」实现，所以需要本机装有 Edge 或 Chrome。脚本会自动探测：

1. 环境变量 `ANKI_BROWSER` 指定的可执行文件
2. `PATH` 上的 `msedge` / `google-chrome` / `chromium` 等
3. Windows / macOS 的常见安装路径

找不到浏览器时会跳过 PDF，HTML 卡册不受影响。也可以随时在网页里按 `P` 手动打印。

## 已知问题

**MarginNote 导出的遮罩层可能丢失**

MarginNote 3 用「挖空 SVG + 答案截图」实现正反面。部分导出版本里 SVG 只剩一个空的 `<g><title>Masks</title></g>`，遮罩内容没写进去 —— 结果就是「题目面」和「答案面」是同一张图，答案没有被盖住。

脚本会检测这种情况（正反面图片集合完全相同），并：

- 在卡册里把翻面按钮置灰成「此卡正面即答案」，加脚注说明
- 打印时只印一次，不浪费纸
- 生成 JSON 时不再重复内嵌这张图，单文件体积可小 20%+

要真正的挖空自测，需要回 MarginNote 重新导出并勾选「遮盖/挖空」。

## 技术说明

`.apkg` 其实是个 zip：

| 文件 | 作用 |
|---|---|
| `collection.anki2` | SQLite 数据库，`notes` 表存卡片，`cards` 表存复习状态 |
| `media` | JSON，`{"0": "abc.jpg", ...}` 把 zip 内的数字文件名映射回真实名 |
| `0`、`1`、`2`… | 媒体文件本体，名字是纯数字索引 |

几个踩过的坑：

- `notes.flds` 字段用 `\x1f`（Unit Separator）分隔，不是逗号
- 牌组名要去 `col.decks` 的 JSON 里找，取卡片数最多的那个（忽略 `Default`）
- 模板字段顺序因导出工具而异，文字类牌组要回退读 `TextFront` / `TextBack`
- MarginNote 会在字段末尾残留 `#标签` 文本节点，需要单独清理
